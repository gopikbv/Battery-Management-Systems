## Battery Management System (BMS) Protection

## Overview
This project implements protection mechanisms for a Battery Management System (BMS) using Simulink. It covers overcurrent, overvoltage, undervoltage, and thermal protections to ensure safe operation of the battery system.

## Features
- **Protection Logic**: Monitors and protects against overcurrent, overvoltage, undervoltage, and temperature.
- **Simulink Models**: Single-cell and multi-cell BMS models.

## Requirements
- MATLAB 2020b or later
- Simulink

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/gopikbv/Battery-Management-Systems/tree/main/Project_3_BMS_Protection
   ```
2. Open the Simulink model (`BMS_Protection_Logic.slx`).
3. Run the simulation.
