# 🚀 Single Cell Battery Management System (BMS)
# 📌 Project Overview
This project focuses on developing a Battery Management System (BMS) for a single lithium-ion cell using MATLAB & Simulink. The system includes protection logics, state estimation algorithms, and data analysis to ensure efficient and safe battery operation.

# ✨ Features
✅ State-of-Charge (SoC) Estimation – Calculates the remaining battery capacity.
✅ Protection Mechanisms – Implements overvoltage, undervoltage, overcurrent, and thermal protection.
✅ Cell Monitoring – Tracks voltage, current, and temperature.
✅ Simulink Implementation – Uses Simulink models & Stateflow for BMS logic.
✅ Data Analysis – Includes test data and simulation results for validation.

# 📂 Directory Structure
