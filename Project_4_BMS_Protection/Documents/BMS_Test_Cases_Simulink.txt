Steps to Test the Logic in Simulink

1. Set Up Inputs:
   - Provide current (C), temperature (T), and voltage (V) as inputs using constant blocks, signal builders, or MATLAB scripts.
   - Ensure you include test signals that simulate boundary and fault conditions for each parameter.

2. Monitor Outputs:
   - Use display blocks, scopes, or logging to monitor the status of FETs (M1, M2, M3) and LED outputs.

3. Validate Behavior:
   - For each test case, compare Simulink outputs (FETs and LEDs) with the expected results outlined in the table.

4. Recovery Testing:
   - Introduce fault conditions, hold them for a specific duration, and then return to safe values to confirm proper recovery behavior (e.g., timing delays).

5. Document Results:
   - Log whether the Simulink model behaves as expected for each test case.
