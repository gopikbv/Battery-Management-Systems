
# Temperature Protection Algorithm for Battery Management System (BMS)

## Project Overview
This project demonstrates the testing and analysis of a **Temperature Protection Algorithm** for a Battery Management System (BMS) using **MATLAB Simulink**. The focus was on ensuring the reliability and performance of the algorithm under various conditions. Both runtime and post-simulation analyses were conducted, covering different test case scenarios.

## Features
- **Runtime Analysis**: Real-time performance evaluation during simulations.
- **Post-Simulation Analysis**: Detailed review of logged data to validate algorithm functionality.
- **Comprehensive Testing**: Simulink Test Manager was used to perform:
  - **Equivalence Test**: Ensured consistency between different implementations.
  - **Simulation Test**: Verified behavior across multiple scenarios.
  - **Baseline Test**: Compared outputs against predefined reference datasets.

## Results
- Captured simulation outputs and evaluated the results for accuracy.
- Conducted coverage analysis to identify areas for improvement and ensure robust testing.
